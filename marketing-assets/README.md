# Gardina — маркетинговые ассеты

Скрины приложения для соцсетей/лендинга. Сняты с демо-стека (реальные данные, RU).
- `screens/desktop/` — 1920×1080 (16:9): лендинг, YouTube, горизонтальные карусели, сайт.
- `screens/mobile/` — 430×932 @2x (9:16): Instagram Reels/Stories, TikTok, мобильные карусели.
- Видео-ролики по ролям: `../remotion-demos/out/{designer,manager,sales,admin}.mp4`

Пересъёмка: поднять демо-стек → `node specs/demos/_marketing-shots.mjs`.

## Десктоп vs мобайл
- **Reels/Stories/TikTok** → бери `mobile/` (вертикаль, нижний навбар = «как на телефоне у дизайнера»).
- **Карусели Instagram** → можно оба; мобайл крупнее читается в ленте.
- **Лендинг/сайт/YouTube** → `desktop/`.

## Быстрые улучшения скринов (по желанию)
- Добавить 1–2 фото тканей в каталог → карточка товара (`14`) оживёт, маржа считается при указании себестоимости.
- В отчётах вкладка «3 месяца» даёт более полную картину выручки.
