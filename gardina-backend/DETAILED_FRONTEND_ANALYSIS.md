## 🔄 ЧТО ПРОИСХОДИТ ПРИ СОХРАНЕНИИ

### В режиме создания (CREATE):
```javascript
await catalogAPI.createFabric(payload);
```
**Что делает backend:**
1. Создает товар в `products`
2. Если есть `colors` в payload, создает каждый цвет в `product_variants`

### В режиме редактирования (EDIT):
```javascript
// 1. Обновить основной товар
await catalogAPI.updateFabric(id, payload);

// 2. Обновить/создать цвета
for (const color of validColors) {
  if (color.id) {
    await catalogAPI.updateProductColor(color.id, color);
  } else {
    await catalogAPI.createProductColor(id, color);
  }
}
```

## 📝 ПРИМЕРЫ КОДА

### Компонент выбора цвета:

```jsx
// ColorSelector.jsx
const ColorSelector = ({ product, selectedVariantId, onChange }) => {
  return (
    <div className="space-y-2">
      <label className="font-medium">Выберите цвет</label>
      {product.variants.map(variant => (
        <div
          key={variant.id}
          onClick={() => onChange(variant)}
          className={`border rounded-lg p-3 cursor-pointer ${
            selectedVariantId === variant.id
              ? 'border-primary bg-primary/5'
              : 'border-gray-200'
          }`}
        >
          <div className="flex items-center justify-between">
            <div className="flex items-center gap-2">
              {variant.hexColor && (
                <div
                  className="size-6 rounded-full border"
                  style={{ backgroundColor: variant.hexColor }}
                />
              )}
              <div>
                <p className="font-medium">
                  {variant.variantName || `Цвет ${variant.variantCode}`}
                </p>
                <p className="text-xs text-gray-500">
                  Код: {variant.variantCode}
                </p>
              </div>
            </div>
            <div className="text-right">
              <p className="text-sm font-medium">
                {variant.stockQuantity} м
              </p>
              <p className="text-xs text-gray-500">
                {variant.isAvailable ? '✓ В наличии' : '✗ Нет'}
              </p>
            </div>
          </div>
        </div>
      ))}
    </div>
  );
};
```
