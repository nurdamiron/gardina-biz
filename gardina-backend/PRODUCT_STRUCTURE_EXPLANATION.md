# 📦 СТРУКТУРА ТОВАРОВ: ПОЛНОЕ ОБЪЯСНЕНИЕ

## 🗄️ СТРУКТУРА БАЗЫ ДАННЫХ

### Таблица 1: `products` (основная информация о товаре)

Хранит **общую информацию** о товаре (один товар = одна запись):

```sql
{
  id: "uuid-123",
  name: "Бархат",                    -- Название товара
  type: "curtain",                   -- Тип (curtain, tulle, etc.)
  description: "Премиум бархат",     -- Описание
  width_cm: 200,                     -- Ширина рулона в см (2м = 200см)
  price_per_meter: 5500,             -- Цена за метр (тенге)
  cost_price: 1000,                  -- Цена закупки (тенге)
  brand: "Турция",                   -- Бренд/страна
  is_available: true,                -- Доступен ли товар
  image_url: "/images/product.jpg"   -- Главное фото товара
}
```

### Таблица 2: `product_variants` (цветовые варианты)

Хранит **варианты цветов** каждого товара (один цвет = одна запись):

```sql
{
  id: "uuid-456",
  product_id: "uuid-123",            -- Ссылка на products
  variant_code: "19",                -- КОД ЦВЕТА (артикул)
  variant_name: "Бежевый",           -- Название цвета (опционально)
  stock_quantity: 70,                -- КОЛИЧЕСТВО НА СКЛАДЕ (для этого цвета)
  hex_color: "#F5F5DC",              -- HEX код цвета (опционально)
  image_url: "/images/color-19.jpg", -- Фото этого цвета
  is_default: true,                  -- Основной цвет?
  is_available: true                 -- Доступен ли этот цвет
}
```

## 🎨 КАК ЭТО РАБОТАЕТ

### Когда клиент заказывает:
1. Выбирает товар: "Бархат"
2. Выбирает цвет: "Артикул 19 (Бежевый)"
3. Указывает метраж: 5 метров
4. **Цена:** 5500 тг/м × 5м = 27,500 тг
5. **Склад:** Вычитаем 5 метров из stock_quantity варианта с кодом "19"

## 🔄 API ENDPOINTS

### Получить товар с цветами:
```
GET /api/products/{id}

Response:
{
  "id": "uuid-123",
  "name": "Бархат",
  "type": "curtain",
  "price_per_meter": 5500,
  "cost_price": 1000,
  "width_cm": 200,
  "variants": [
    {
      "id": "uuid-456",
      "variant_code": "19",
      "variant_name": "Бежевый",
      "stock_quantity": 70.3,
      "is_default": true
    },
    {
      "id": "uuid-457",
      "variant_code": "46",
      "variant_name": "Серый",
      "stock_quantity": 120.1,
      "is_default": false
    }
  ]
}
```

### Создать товар с цветами:
```
POST /api/products

Body:
{
  "name": "Бархат",
  "type": "curtain",
  "price_per_meter": 5500,
  "cost_price": 1000,
  "width_cm": 200,
  "variants": [
    {
      "variant_code": "19",
      "variant_name": "Бежевый",
      "stock_quantity": 70.3
    },
    {
      "variant_code": "46",
      "variant_name": "Серый",
      "stock_quantity": 120.1
    }
  ]
}
```

### Обновить количество цвета на складе:
```
PATCH /api/products/{productId}/variants/{variantId}

Body:
{
  "stock_quantity": 65.3  // Было 70.3, продали 5 метров
}
```

## ✅ ПРЕИМУЩЕСТВА ТАКОЙ СТРУКТУРЫ

1. **Разделение данных:**
   - Основная информация (название, цена) в одном месте
   - Варианты цветов отдельно - легко добавлять/удалять

2. **Учет склада:**
   - Точное количество для каждого цвета
   - Можно видеть какой цвет заканчивается

3. **Гибкость:**
   - Легко добавить новый цвет
   - Можно выключить определенный цвет (is_available = false)

4. **Масштабируемость:**
   - Если нужно добавить цену для каждого цвета - просто добавим поле в variants
   - Можно добавить фото для каждого цвета
