# Изображения для лендинга

Лендинг SaaS **Gardina** негізінен мәтін, иконкалар және CSS-блоктармен жұмыс істейді (hero үшін `hero-main.jpg` міндетті емес).

## Қажетті файлдар

| Файл | Өлшем | Сипаттама |
|------|--------|-----------|
| **`logo-header.png`** | негізгі бренд логотип | Хедер, футер — `/images/logo-header.png` |
| `favicon.png` | 32×32 | Браузер иконкасы (актуалды `Лого.png` негізінде) |

## Open Graph

| Файл | Өлшем | Сипаттама |
|------|--------|-----------|
| `og-image.jpg` | 1200×630 | Әлеуметтік желілер мен бөлісу үшін сурет (Gardina SaaS интерфейсі немесе бренд слайды) |

---

Суреттерді өзіңіздің бренд нұсқаңызбен ауыстырыңыз немесе `gardina.kz` бойынша жаңартыңыз.
