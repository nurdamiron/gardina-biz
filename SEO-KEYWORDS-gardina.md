# SEO/GEO keyword research — Gardina

## Ниша
Gardina — B2B CRM/ERP для салонов штор и текстильного дизайна в Казахстане (мобильное приложение + веб-платформа, kz.gardina.app). Не витрина для покупателей штор — инструмент для владельца/сотрудников салона: клиенты и сделки, замеры с фото (мм, тип монтажа), каталог тканей и услуг с расчётом стоимости, производственные статусы (раскрой → пошив → контроль качества → готово), монтаж, аналитика. Билингвальный рынок (ru_KZ/kk_KZ).

## Целевой клиент
Владелец или менеджер салона штор/ателье в Казахстане — не конечный покупатель штор. Ищет решения операционных проблем: путаница в заказах, потерянные замеры, споры с клиентом по стоимости, задержки производства.

## Текущее состояние
**Блога нет вообще** — gardina.kz это статический лендинг, `/blog` отдаёт fallback лендинга (SPA), не реальный контент. Ничего писать некуда, пока не построен раздел блога (роуты + хранилище контента) на gardina-frontend. Это исследование — база для той будущей работы, не готовые посты.
